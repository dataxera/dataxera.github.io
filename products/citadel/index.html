02 // DEPLOYMENT FLEXIBILITY

Run Where Your Business & Compliance Rules Demand.

Because Dataxera Citadel is built on standard Kubernetes, your organization is never trapped in a single hosting model. Start on-premise, expand to the cloud, or operate air-gapped sovereign environments.

OPTION 01 // ON-PREMISE & PRIVATE CLOUD

Your Own Data Center

Ideal for government agencies, banks, and regulated enterprises that require sensitive data to remain strictly inside physical walls or air-gapped networks.

  • Eliminates recurring public cloud egress & compute fees
  • Supports lightweight bare-metal Kubernetes (k3s)
  • Full physical and regulatory data residency
OPTION 02 // PUBLIC CLOUD KUBERNETES

AWS, Google Cloud & Azure

Deploy Citadel onto your existing cloud Kubernetes service to leverage elastic cloud compute—without locking yourself into proprietary cloud-only data warehouses.

  • Portable across AWS EKS, Google GKE, and Azure AKS
  • Store data in open formats inside your own cloud buckets
  • Negotiate cloud infrastructure purely as a commodity
