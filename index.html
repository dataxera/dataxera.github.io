01 // ENTERPRISE PLATFORM ARCHITECTURE

Why Organizations Standardize on Dataxera Citadel.

Assembling an enterprise data platform from standalone open-source tools usually requires months of brittle scripts, manual certificate management, and fragmented authentication. Dataxera Citadel turns Kubernetes into a cohesive, self-governing data & AI appliance.

PILLAR 01 // ORCHESTRATION

Operator-Driven Kubernetes Lifecycle

Citadel provisions and reconciles best-of-breed Kubernetes operators—including CloudNativePG, Strimzi, NiFiKop, Doris Operator, and Argo CD—through a unified declarative control plane.

Argo CD v2.14.2 + Custom CRDs Automated Reconciliation
PILLAR 02 // SECURITY & PKI

Zero-Touch End-to-End TLS & Gateway Routing

Every deployed component—from NiFi JKS keystores and Trino HTTPS coordinators to Kafka mTLS listeners and PostgreSQL replication—is automatically secured via cert-manager and exposed cleanly through Envoy Gateway.

cert-manager v1.20.0 + Envoy v1.8.1 Per-Project Wildcard TLS
PILLAR 03 // RESILIENCY

Topological Service Dependency Protection

Citadel’s built-in Dependency Tracker maintains a strict directed graph of service relationships. Upstream databases, S3 stores, or metastores cannot be accidentally decommissioned while downstream engines depend on them.

Stateful Dependency Graph Orphan-Free Operations
PILLAR 04 // GOVERNANCE

Multi-Tenant Projects & Centralized Identity

Isolate workloads by department, agency, or environment using Citadel Projects. Integrate corporate LDAP directories and Dex OIDC authentication with granular role-based access control.

Dex v2.41.1 + LDAP Integration Namespace Isolation
PILLAR 05 // CONNECTIVITY

First-Class Enterprise Resource Registry

Manage S3-compatible object storage connections, Git repositories for Airflow DAGs, SSH keys, private container registries, external database sources, and custom CA certificates from a single pane of glass.

Encrypted Secret Vaulting Reusable Across Engines
PILLAR 06 // SOVEREIGNTY

100% Open Source & Cloud-Agnostic

Licensed under GNU AGPLv3 with locked, reproducible stack manifests (`citadel-0.1.0`). Run identically on air-gapped on-premise bare metal (`k3s` + `MetalLB`) or managed cloud Kubernetes (`EKS`, `GKE`, `AKS`).

SPDX: AGPL-3.0-or-later Full Data Sovereignty
